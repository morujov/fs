## 2. Что сделано с 15.07

### Дизайн-ревью пятью агентами
Заведены проектные субагенты `.claude/agents/` (backend-laravel, frontend-blade,
ux-designer, ui-expert, product-manager) — премиальные роли с зашитыми
инвариантами. Через них прогнан набор идей по витрине; продакт свёл в план
инкрементов. Агенты переиспользуемы через `/agents`.

### Полировка витрины (PR #11)
- **Дизайн-токены** в `app.css`: нейтраль-бумага + один латунно-золотой акцент
  («красота/ценность» номера), `:root` + `@theme inline`. Тёмная тема отложена.
- **Контекстный фон** — тихий inline-SVG-паттерн (телефонная сетка + призрачные
  цифры), fixed, aria-hidden, гаснет к низу. Zero-CDN.
- **Раскладка**: категории подняты под поиск; `condition` → сегмент-пилюли;
  `sort` вынесен к действиям. Карточка: номер-герой, паттерн-теги в латунь,
  контакт — «запертое поле» с иконкой-замком (без blur, инвариант №2).
- Тач-таргеты 44px, семантические токены вместо хардкода.
- Попутно два бага: сортировка провинций по локали; `province[]` → скаляр.

### Английский интерфейс + переключатель (PR #9)
`SetLocale`-middleware (сессия → профиль → дефолт es), `GET /idioma/{locale}`,
`<x-locale-switcher>`. Без авто-детекта по Accept-Language (SEO: канон стабильно
испанский). Строки уже были в `lang/es|en`.

### Обрезка фильтров + автокомплит (PR #10, #12)
- Убраны фильтры оператора/типа линии/permanencia с витрины.
- **Автокомплит провинций** — ванильное прогрессивное улучшение `<select>`
  (без Alpine): фильтр по вводу, нечувствительный к диакритике (mal→Málaga),
  ARIA/клавиатура; нативный select остаётся no-JS/SEO-полом.

### Поиск ячейками + снятие оператора (ветка `search-cells-remove-operator`, PR открыт)
- **Поле поиска номера — 9 отдельных ячеек** (по цифре в клетке, как на Nömrem):
  прогрессивное улучшение, значение синкается в скрытый `q`, пустая клетка в
  середине = `?`. Без JS — обычное поле.
- **Оператор убран** — из формы подачи, фильтра, карточки и страницы карточки.
  Колонка `operator_id` осталась nullable в БД и в Filament.

### Mobile-QA (в том же PR)
Сайт ждём преимущественно с телефонов. Прогон на 320/375/414 нашёл и починил:
- **Пагинация показывала сырые ключи** `pagination.next/previous` (не было
  `lang/*/pagination.php`) — видимый баг → добавлены переводы.
- **iOS Safari авто-зум** на инпутах <16px (`Ordenar`) → контролы форм ≥16px на
  мобиле.
- Шапка вылезала за край на 320px → `flex-wrap`; сортировка — своя строка;
  `overflow-x: clip` как гард.

**Где живёт:** дроплет DigitalOcean **openmarket** (id 581774280, IP 138.68.89.3,
Ubuntu 24.04, **1 vCPU / 1 ГБ**). ⚠️ На этом же дроплете крутится **боевой
`play.cac.az`** (Node + PM2 + nginx TLS). Поэтому деплой изолирован:
- Свой каталог `/opt/numeros-es`, отдельная БД `numeros_demo` + MySQL-юзер, свой
  nginx server-block. Конфиги и приложение play.cac.az не тронуты.
- **Добавлен 2 ГБ swap** как подушка от OOM (на 1 ГБ рядом с живым соседом).
- MySQL 8 с крошечным буфером (64M), PHP 8.3-FPM. Ассеты и vendor собраны локально
  → на дроплет ехал тарбол (composer/npm на дроплете не запускались).
- Демо-данные засеяны (487 объявлений); `DatabaseSeeder` в production их
  пропускает — сеялись `DemoListingSeeder` с временным `APP_ENV=local`.

**Снос завтра:** `bash /root/teardown-numeros.sh` — убирает nginx-сайт, БД+юзер,
`/opt/numeros-es`, htpasswd, **временный SSH-ключ** (отзывает доступ), и purge
php+mysql (возвращает RAM play.cac.az). Swap оставляет (полезен соседу). В конце
сам проверяет, что play.cac.az жив.
